# AllOne 项目需求规格说明书

> 版本：0.1（初稿）
> 类型：个人开发的跨平台软件项目
> 参考产品：滴答清单、一本记账、一本日记

## 1. 项目定位

**AllOne** 是一个个人全功能生活管理软件，将六大核心功能（日记、待办、习惯、课程表、记账、日历）整合到同一个应用中，数据完全本地保存、格式通用、可离线使用。

### 1.1 目标平台

| 平台 | 支持 | 说明 |
|------|------|------|
| Android（手机） | ✅ | 主目标平台 |
| Windows（电脑） | ✅ | 主目标平台 |
| iOS / iPadOS（平板） | 🔶 | 代码跨平台，需在 macOS 上编译发布 |

### 1.2 核心原则

1. **信息安全第一**：数据默认保存在本地；云同步不作为默认方案；若启用须端到端加密。
2. **运行稳定**：模块化 + 风险隔离，一个功能出错不影响整个应用。
3. **格式通用**：核心内容用标准格式（Markdown/txt/JSON）记录，不依赖私有数据库，便于长期保存、迁移和 U 盘手动备份。

## 2. 功能模块总览

```
AllOne
├── 日记 (Diary)
├── 待办事项 (Todo)
├── 习惯 (Habit)
├── 课程表 (Schedule)
├── 记账 (Ledger)
└── 日历 (Calendar)
```

- 模块化设计，六大功能彼此独立（独立的数据目录、独立的代码模块）。
- 日历模块作为「聚合视图」，读取其余模块的数据。

## 3. 日记模块

### 3.1 模板设计
- 支持创建日记模板（定义一篇日记的默认结构：标题、分区、内容类型占位等）。
- 写日记时可选择模板快速生成。

### 3.2 日记内容（多媒体）
- 文本：纯文本编辑（类似 txt，手机 / 电脑键盘友好）。
- 录音：内嵌录音文件。
- 照片：插入图片附件。
- 视频：插入视频附件。
- 文件：任意文件附件。
- **大视频处理**：超过阈值（如 50MB）的视频不直接内嵌，改为「外链引用」——保存文件路径或外部存储位置，正文中以链接形式引用，避免数据膨胀。

### 3.3 三种「戳」（Stamp）
| 戳 | 功能 | 说明 |
|----|------|------|
| 时间戳 | 历史纪念 | 可在半年 / 一年等时间节点自动置顶，作为历史纪念 |
| 地址戳 | 地点标记 | 内嵌可视化地图选点；支持**一键获取系统定位**（手机 GPS，离线可用）、**多底图源切换**、**本地离线瓦片** |
| 标签戳 | 分类检索 | 给日记打标签，方便分类与查找 |

### 3.4 外部日记导入（txt / PDF）
- **用途**：把用户此前在其他软件（记事本、印象笔记、OneNote、其他日记 App）写的日记迁移进 AllOne。
- **来源格式**：`.txt`（首选，自动识别 UTF-8（含 BOM）/ UTF-16 / GBK 编码，避免中文乱码）、文本型 `.pdf`；支持多选。
- **自动分篇**：识别「日期标题行」（如 `2024年5月1日 星期三 晴`、`2024-05-01`、`20240501`、`5月1日`）把长文件拆成多篇；
  另可选「整篇作为一篇」「按空行分段」。识别到的日期作为该篇日记的日期（日历 / 时间轴顺序与原来一致）。
- **导入前预览**：逐篇展示标题 / 日期 / 字数 / 来源文件，可单独勾选、可查看正文全文。
- **不覆盖原则（硬性要求）**：导入只**新增**日记文件并分配全新 ID；
  不得修改、覆盖或删除任何已有日记；导入失败或取消也不影响现有数据。
- **重复保护**：按「标题 + 日期 + 正文」比对现有日记，标记疑似重复项并默认跳过（可关闭）。
- **统一标签**：可为本次导入的所有日记统一添加标签（如「导入」），便于后续检索与回溯。
- **已知限制**：扫描件 / 图片型 PDF 无文字层，导入前需在原软件导出为 txt 或文字版 PDF。

## 4. 待办事项模块

### 4.1 模板
- 待办模板包含：**截止时间**、**地点**。
- 对截止时间与地点提供**颜色标记**与**醒目位置展示**（如置顶、高亮）。

### 4.2 文本格式
- **纯文本模式**：类似 `.txt`，简单直接。

### 4.3 附件
- 每个待办可附带：录音、照片、视频、文件附件。
- **点一下即打开**：附件行（含缩略图）本身可点，不需要先找到右侧小按钮；
  照片 → 全屏查看（可缩放），录音 → 内置播放器（播放 / 暂停 / 进度 / 时长），
  视频 → 播放器，文件 → 交给系统默认程序。
- 附件文件缺失时**明确提示**并显示完整路径（可复制），不再「点了没反应」。

### 4.4 树形待办（任务链）
- 待办统一为**树形结构**：普通待办可嵌套任意层级的**子任务**（即任务链）。
- 每个节点（含子任务）都拥有完整功能：标题、正文、截止时间、地点、标签、附件、状态。
- 待办列表树形展开 / 折叠展示；每个节点可添加子任务、勾选完成、编辑、删除。

## 5. 习惯模块

- 习惯 = 一种**特殊的长期任务**。
- 核心记录维度：
  - **持续时间或次数**（如连续打卡天数 / 累计次数）
  - **习惯内容**
  - **习惯分类**
- 习惯描述的格式为**纯文本**，可附附件。

## 6. 课程表模块

- 课程表 = 一种**特殊习惯**，**半年一换**（学期制）。
- 核心字段：每门课程的**时间**与**地点**。
- 两种界面：
  1. **每周界面（传统课程表）**：按周一到周日展示课程名、时间、地点。
     - **两种排布都保留，可随时切换**：右上角「网格 / 按天」；
     - **网格**：宽屏（电脑）按可用宽度平分 7 列，正好铺满窗口、不需要左右平移；
       超宽屏列宽封顶；窗口太窄时（手动手选网格）才退化为横向平移，且不再有上下分别滚动；
     - **按天**：一天一段的纵向列表（手机友好），整页只需上下滚动；
     - 默认**按窗口宽度自动选**（< 560 逻辑像素用「按天」，否则「网格」）；
       手动切换后**会记住**（写入 `AllOneData/settings/ui.json`，重启仍然生效），
       并出现「恢复自动」，可随时切回自动。
  2. **课程集中统计界面**：列出所有课程的基础信息 + 课程说明（用于记录课程要求、相关资料）。

## 7. 记账模块

- **总账本**：一个记账应用对应一个总账本。
- **账户**：账本内可自由创建多个账户（如：现金、银行卡、支付宝、微信）。
- **记账**：对每个账户分别记录收支明细。
- **统计**：
  - 对每个账户：按月统计、按年统计。
  - 对总账本：按月统计、按年统计。

## 8. 日历模块

### 8.1 三种界面
| 界面 | 内容 |
|------|------|
| **当天** | 集中展示当天的待办、习惯、课程表项目，按 deadline 时间从早到晚排序；当天若有特殊日子（含每年重复的生日 / 纪念日）在顶部先提示 |
| **当月** | 不列细节；用可视化标记每天完成情况；标注法定节假日与特殊日子（特殊日子在日历界面直接创建，不属于待办/习惯；颜色可**任意自定义**：常用色板 + RGB 微调 + 十六进制输入，创建后可点按修改名称与颜色） |
| **当年** | 当月界面的精简版，12 个月缩至同一页面，内容一致 |

### 8.2 特殊日子 · 倒数日（总览页）
- 入口：日历右上角「特殊日子 / 倒数日」图标。
- **按时间排列**，避免日子散落在各月格子里想不起来、找不到：
  - 「即将到来」：今天（0 天）排最前，其余按天数从小到大；
  - 「已经过去」：最近过去的排前面。
- 每条显示：名称、日期、**倒数天数**（今天 / 还有 N 天 / 已过 N 天）、自定义颜色；点整行即可编辑，右侧可删除。
- **每年重复**：生日 / 纪念日打开该开关后，每年这一天都会自动出现在日历里并倒数，
  同时显示「第 N 周年」；不重复的日子过了就是「已过 N 天」。
- 新增流程：右下角「添加」→ 选日期 → 填名称 / 选颜色 / 勾选每年重复。

## 9. 更新与卸载（2026-10-07 新增）

### 9.1 应用内一键更新（Windows / Android）
- **检查**：设置页「检查更新」手动触发；启动时也会**静默检查一次**（每天最多一次，
  网络失败不打扰用户）。数据源为 GitHub Releases 的 `releases/latest`。
- **提示**：显示新版本号、发布说明、安装包名与体积；可「跳过此版本」（记进偏好，不再提示）。
- **一键更新**：应用内下载 →（可选）备份数据 → 覆盖安装：
  - Windows：以 `/SILENT /SUPPRESSMSGBOXES /NORESTART /CLOSEAPPLICATIONS` 静默运行安装包，
    装完自动打开新版本；
  - Android：下载 APK → 申请「安装未知应用」权限 → 调起系统安装界面，确认即覆盖安装。
- **数据不变**：更新只替换程序文件，`文档\AllOneData` 完全不受影响。
- **兜底**：从 1.2.1 及更早版本升级时默认**先复制一份数据目录**再安装
  （那些版本的卸载程序会删数据，见 9.2）。

### 9.2 卸载与数据清理
- 卸载时**弹窗询问**「是否同时删除全部个人数据」，**默认按钮为「否」（保留数据）**。
- 选择「是」→ 连同文件夹删除 `文档\AllOneData`（日记 / 待办 / 习惯 / 课程 / 记账 /
  日历 / 附件 / 地图瓦片 / 设置），即**全部使用痕迹**。
- 安装新版时会自动卸载旧版，但安装脚本**不再无条件删除数据目录**
  （1.2.1 及更早的旧脚本有此隐患，用它升级会静默删数据，已修复并成为默认行为）。

### 9.3 发布签名（前提条件）
- Android 只允许**签名一致**的 APK 覆盖安装，因此发布必须使用固定的
  `android/allone-release.jks`（随仓库保存，个人自用项目）；用 debug 签名会导致
  新版本装不上、只能卸载重装（数据全丢）。详见 [构建指南](BUILD.md)。

## 10. 编辑模式

- 日记书写时符合手机与电脑的键盘习惯，提供**两套编辑模式**：
  1. **手机模式**：触屏友好、大按钮、语音输入优先。
  2. **电脑模式**：全键盘、快捷键、Markdown 直接编辑。

## 11. 数据与同步

- 数据全部本地存储，采用**通用格式**（详见 `DATA_FORMAT.md`）。
- 提供**备份/恢复**功能：
  - U 盘手动备份（复制数据目录）——默认推荐方式。
  - 可选：加密云同步（设计预留接口，默认关闭）。
- 大文件（视频等）支持外链引用，减小备份体积。

## 12. 界面风格

- 简洁**白色**主题。
- 字体与组件使用成熟方案（Material 3 / 系统默认）。
- 强调可读性与稳定性，不追求花哨。

## 14. 第二轮测试反馈修复（2026-08-22）

| 反馈问题 | 修复内容 |
|---------|---------|
| 时间戳需手动输入日期 | 新增**快捷节点按钮：一个月后 / 半年后 / 一年后**，一键生成纪念节点 |
| 地址戳只是经纬度 | 地址戳对话框**内嵌可视化地图**（点击直接选点），日记详情页也**展示地图标记** |
| 日记没出现在日历 | 日历**当天视图显示当天日记**；当月视图日期格加日记标记；当年视图显示每月日记数 |
| 找不到课程表 | 课程表**已加入底部主导航**（第 4 个标签），与抽屉入口并存 |
| 记账流水丢失（月/年统计没有它） | **修复存储读写不一致 bug**（写入扁平文件但按子目录读取，导致流水读不出）；现可正常显示与统计 |
| 记账缺"本日"界面 | 记账新增 **今日 / 本月 / 本年** 三视图切换；今日视图显示今日流水 |
| 记账缺计划支出 | 新增**本月预算**设置，月度界面显示**日均支出、本月预算、剩余每天可花额度** |

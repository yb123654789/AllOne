# AllOne 项目需求规格说明书

> 版本：0.1（初稿）
> 类型：个人开发的跨平台软件项目
> 参考产品：滴答清单、一本记账、一本日记

## 1. 项目定位

**AllOne** 是一个个人全功能生活管理软件，将六大核心功能（日记、待办、习惯、课程表、记账、日历）整合到同一个应用中，数据完全本地保存、格式通用、可离线使用。

### 1.1 目标平台

| 平台 | 支持 | 说明 |
|------|------|------|
| Android（手机） | ✅ | 主目标平台 |
| Windows（电脑） | ✅ | 主目标平台 |
| iOS / iPadOS（平板） | 🔶 | 代码跨平台，需在 macOS 上编译发布 |

### 1.2 核心原则

1. **信息安全第一**：数据默认保存在本地；云同步不作为默认方案；若启用须端到端加密。
2. **运行稳定**：模块化 + 风险隔离，一个功能出错不影响整个应用。
3. **格式通用**：核心内容用标准格式（Markdown/txt/JSON）记录，不依赖私有数据库，便于长期保存、迁移和 U 盘手动备份。

## 2. 功能模块总览

```
AllOne
├── 日记 (Diary)
├── 待办事项 (Todo)
├── 习惯 (Habit)
├── 课程表 (Schedule)
├── 记账 (Ledger)
└── 日历 (Calendar)
```

- 模块化设计，六大功能彼此独立（独立的数据目录、独立的代码模块）。
- 日历模块作为「聚合视图」，读取其余模块的数据。

## 3. 日记模块

### 3.1 模板设计
- 支持创建日记模板（定义一篇日记的默认结构：标题、分区、内容类型占位等）。
- 写日记时可选择模板快速生成。

### 3.2 日记内容（多媒体）
- 文本：纯文本编辑（类似 txt，手机 / 电脑键盘友好）。
- 录音：内嵌录音文件。
- 照片：插入图片附件。
- 视频：插入视频附件。
- 文件：任意文件附件。
- **大视频处理**：超过阈值（如 50MB）的视频不直接内嵌，改为「外链引用」——保存文件路径或外部存储位置，正文中以链接形式引用，避免数据膨胀。

### 3.3 三种「戳」（Stamp）
| 戳 | 功能 | 说明 |
|----|------|------|
| 时间戳 | 历史纪念 | 可在半年 / 一年等时间节点自动置顶，作为历史纪念 |
| 地址戳 | 地点标记 | 内嵌可视化地图选点；支持**一键获取系统定位**（手机 GPS，离线可用）、**多底图源切换**、**本地离线瓦片** |
| 标签戳 | 分类检索 | 给日记打标签，方便分类与查找 |

### 3.4 外部日记导入（txt / PDF）
- **用途**：把用户此前在其他软件（记事本、印象笔记、OneNote、其他日记 App）写的日记迁移进 AllOne。
- **来源格式**：`.txt`（首选，自动识别 UTF-8（含 BOM）/ UTF-16 / GBK 编码，避免中文乱码）、文本型 `.pdf`；支持多选。
- **自动分篇**：识别「日期标题行」（如 `2024年5月1日 星期三 晴`、`2024-05-01`、`20240501`、`5月1日`）把长文件拆成多篇；
  另可选「整篇作为一篇」「按空行分段」。识别到的日期作为该篇日记的日期（日历 / 时间轴顺序与原来一致）。
- **导入前预览**：逐篇展示标题 / 日期 / 字数 / 来源文件，可单独勾选、可查看正文全文。
- **不覆盖原则（硬性要求）**：导入只**新增**日记文件并分配全新 ID；
  不得修改、覆盖或删除任何已有日记；导入失败或取消也不影响现有数据。
- **重复保护**：按「标题 + 日期 + 正文」比对现有日记，标记疑似重复项并默认跳过（可关闭）。
- **统一标签**：可为本次导入的所有日记统一添加标签（如「导入」），便于后续检索与回溯。
- **已知限制**：扫描件 / 图片型 PDF 无文字层，导入前需在原软件导出为 txt 或文字版 PDF。

## 4. 待办事项模块

### 4.1 模板
- 待办模板包含：**截止时间**、**地点**。
- 对截止时间与地点提供**颜色标记**与**醒目位置展示**（如置顶、高亮）。

### 4.2 文本格式
- **纯文本模式**：类似 `.txt`，简单直接。

### 4.3 附件
- 每个待办可附带：录音、照片、视频、文件附件。
- **点一下即打开**：附件行（含缩略图）本身可点，不需要先找到右侧小按钮；
  照片 → 全屏查看（可缩放），录音 → 内置播放器（播放 / 暂停 / 进度 / 时长），
  视频 → 播放器，文件 → 交给系统默认程序。
- 附件文件缺失时**明确提示**并显示完整路径（可复制），不再「点了没反应」。

### 4.4 树形待办（任务链）
- 待办统一为**树形结构**：普通待办可嵌套任意层级的**子任务**（即任务链）。
- 每个节点（含子任务）都拥有完整功能：标题、正文、截止时间、地点、标签、附件、状态。
- 待办列表树形展开 / 折叠展示；每个节点可添加子任务、勾选完成、编辑、删除。

### 4.5 排序（2026-10-11 新增）
- **排序方式**（右上角排序按钮，选择会记住）：
  - **手动排序**：你自己排的顺序；
  - **按截止时间**（默认，保持旧行为）：近的在前，**没有截止时间的排最后**；
  - **按创建时间**：最近创建的在前；
  - **按标题**：升序。
  - 除手动外，未完成的条目都排在已完成 / 已归档之前。
- **上移 / 下移**：**顶层待办与每一层子任务**的「⋮」菜单里都有。
  - 顶层改 `order`；子任务直接重排父节点的 `children` 数组。
  - **不在手动模式时点它会自动切到手动**：先把当前显示顺序固化成 `order`
    （所以顺序不会突变），再执行移动。
- **切到「手动」时**：若 `order` 还没初始化（旧数据），按当时的显示顺序固化一次（`1..n`）。
- **新建待办**：在手动模式下**按截止时间插到合适位置**（没有截止时间的排最后）；
  其它模式下顺序由排序规则决定。
- **排序方式只作用于顶层**：子任务的顺序始终由你手动排，不会被自动排序覆盖。

## 5. 习惯模块

- 习惯 = 一种**特殊的长期任务**。
- 核心记录维度：
  - **持续时间或次数**（如连续打卡天数 / 累计次数）
  - **习惯内容**
  - **习惯分类**
- 习惯描述的格式为**纯文本**，可附附件。
- **三个维度的节奏**：
  - **频率** `frequency`：每天 / 每周固定几天 / 每 N 天 / 每周 N 次；
  - **当天目标** `dailyTarget`：一次即完成 / 当天累计 N 次（量）/ 当天累计 N 分钟；
  - **坚持周期** `persistence`：不限 / 坚持 N 天 / 累计 N 次 / N 天一轮。
- **「完成」以当天目标为准**（2026-10-11 修正）：
  - 设了「每天累计 8 次」的习惯，打 1 次只算**部分完成**（卡片显示「打卡 1/8」+ 进度条），
    **满 8 次才算完成**（进度条转绿、按钮显示「已完成」）；分钟型同理。
    > 修正前用「有记录即完成」，打一次就变绿勾，这是错的。
  - 卡片同时显示两条进度：**当天目标进度**（主条 + 文案）与**坚持周期进度**（细条 + 文字）。
  - 「每周 N 次」的习惯在卡片上显示「本周 2/3 次」，达成后带 ✓。
- **打卡热力图**（2026-10-11 新增）：
  - 习惯卡片内嵌**最近 15 周**小热力图；点热力图进入**习惯详情页**看**近一年**大图
    （可横向滚动）+ 近一年统计（已完成 / 未完全完成 / 漏打卡 / 标记未完成 的天数与达标率）。
  - 五种状态可分辨并配图例：**已完成（绿）· 未完全完成（黄）· 漏打卡（浅红）·
    标记未完成（深红）· 未安排（灰）**；悬停 / 长按显示具体日期与状态。
  - **计划日**的口径：每天 → 每天；每周几天 → 只算选中的星期；
    每 N 天 → 从**创建日**起每 N 天；每周 N 次 → **没有固定计划日**（不判漏打卡，
    改为在热力图列顶显示该周达成情况 `2/3` 或 `✓`）。
  - 习惯**创建之前**的日子、以及**未来**的日子一律「未安排」（不参与评价，
    否则热力图上会出现大片误导性的「漏打卡」）。
- **手动补打卡 + 修改记录**（2026-10-11 新增）：
  - 详情页热力图上**点选日期**（可多选 = 批量），点「修改选中」后选择
    **补打卡（可填每天补记多少，默认 1）/ 标记未完成 / 清除记录**；
  - **必须填写原因**，否则不允许提交；本来就是目标状态的天数不会被改动、也不留记录；
  - 每次修改都写入**修改记录**（时间、动作、动了哪些天、**改前值**、原因），
    可在详情页右上角「修改记录」回看 —— 修改历史记录这件事必须留痕。

## 6. 课程表模块

> **2026-10-11 改版**：
> - **引入节次 + 可编辑作息表**：课程只选「第几节」（下拉，可连堂），时间由作息表决定，
>   不再手填开始 / 结束时间；
> - **一门课可有多个时段**（同课不同天 / 不同教室），统计里仍是一门课；

> - **周网格照课表截图重做**：左侧节次时间轴 + 顶部日期行（今天实心圆）+ 色块课程，
>   **7 列铺满屏幕、不需要左右滑**；
> - **删掉「按天」排布**：看「今天上什么课」的场景移到「日历 → 当天」的日程表（见 8.3）；
> - **入口调整**：「课程统计 / 学期管理 / 添加课程」都在**工具页**，
>   课程表页本身只留周网格（更干净、空间不局促）；点网格里的课程块可直接编辑该课程。

- 课程表 = 一种**特殊习惯**，**半年一换**（学期制）。
- 核心字段：每门课程的**时间**与**地点**。
- 两种界面：
  1. **每周界面（传统课程表）**：按周一到周日展示课程名、时间、地点。
     - **两种排布都保留，可随时切换**：右上角「网格 / 按天」；
     - **网格**：宽屏（电脑）按可用宽度平分 7 列，正好铺满窗口、不需要左右平移；
       超宽屏列宽封顶；窗口太窄时（手动手选网格）才退化为横向平移，且不再有上下分别滚动；
     - **按天**：一天一段的纵向列表（手机友好），整页只需上下滚动；
     - 默认**按窗口宽度自动选**（< 560 逻辑像素用「按天」，否则「网格」）；
       手动切换后**会记住**（写入 `AllOneData/settings/ui.json`，重启仍然生效），
       并出现「恢复自动」，可随时切回自动。
  2. **课程集中统计界面**：列出所有课程的基础信息 + 课程说明（用于记录课程要求、相关资料）。

## 8. 日历模块

### 8.1 三种界面
| 界面 | 内容 |
|------|------|
| **当天** | **当天日程表**（2026-10-11 改版）：把**课程 + 有精确时分的待办 + 任务/里程碑**合并成一条**时间轴**（按时间排序）；**没有精确时分的**条目（只有日期的待办 / 任务 / 里程碑）单独一区，并**可以直接给它安排时间**（写回原条目）。每条都能点回原处处理（待办 → 待办编辑页、任务/里程碑 → 任务详情页、课程 → 课程编辑页），待办还能在这里直接勾选完成。日程表下方保留：今天的特殊日子、日记、习惯打卡 |
| **当月** | 不列细节；用可视化标记每天完成情况；标注法定节假日与特殊日子（特殊日子在日历界面直接创建，不属于待办/习惯；颜色可**任意自定义**：常用色板 + RGB 微调 + 十六进制输入，创建后可点按修改名称与颜色） |
| **当年** | 当月界面的精简版，12 个月缩至同一页面，内容一致 |

### 8.2 特殊日子 · 倒数日（总览页）
- 入口：日历右上角「特殊日子 / 倒数日」图标。
- **按时间排列**，避免日子散落在各月格子里想不起来、找不到：
  - 「即将到来」：今天（0 天）排最前，其余按天数从小到大；
  - 「已经过去」：最近过去的排前面。
- 每条显示：名称、日期、**倒数天数**（今天 / 还有 N 天 / 已过 N 天）、自定义颜色；点整行即可编辑，右侧可删除。
- **每年重复**：生日 / 纪念日打开该开关后，每年这一天都会自动出现在日历里并倒数，
  同时显示「第 N 周年」；不重复的日子过了就是「已过 N 天」。
- 新增流程：右下角「添加」→ 选日期 → 填名称 / 选颜色 / 勾选每年重复。
- **生命周期（自动维护，2026-10-11 新增）**：
  - **单次**日子（考试等，未开每年重复）：**过了当天**（次日）才算过期，当天仍是「今天」。
    进入本页时会弹窗列出全部过期项，**经用户确认**后移入回收站；
    若选「暂不处理」，「已经过去」分组右上角的「全部归档」可随时手动归档。
  - **每年重复**的日子：过了当天会自动把日期**推进到下一次**（生日滚到明年），
    倒数恒为正；**原始日期会被记住**，所以「第 N 周年」不会因推进而错乱。
    启动 App 时也会静默推进一次（幂等，无变化不写盘）。
  - **回收站**：本页右上角图标进入（带数量角标），可**恢复**、**彻底删除**或**清空回收站**。
    归档项不再出现在日历格子与倒数日列表里，也不参与文本导出。
  - 闰日（2 月 29 日）在平年顺延到 2 月 28 日，不会再错误显示成「今天」。

## 9. 任务模块（2026-10-11 新增）

> 「任务」脱胎于待办，但放的是**需要经年累月做的事**（长期项目、要练的本事、要啃的大事），
> 目的是让「接下来的工作重心」一目了然。它与待办是**两个独立模块**：
> 待办管「这几天要做什么」，任务管「这半年、这几年在做什么」。

- **入口**：底部导航「任务」（可在「工具 → 底部导航显示设置」里隐藏）。
- **字段**：任务名、**目标 / 愿景描述**（为什么做、想达成什么）、领域分类、状态
  （**进行中 / 暂停 / 已完成 / 已放弃**）、起始日期、期望完成日期（**可留空 = 长期无期限**）、
  手动进度、**钉住**（当前重心）。
- **里程碑（阶段）**：把长期任务切成几段逐个推进（可设计划日期）。
  **进度口径：有里程碑 → 按完成数自动算；没有里程碑 → 用手动百分比**
  （长期事情的进度往往是主观的）。
- **行动项（关联待办）**：把「下一步要做什么」关联到待办（**只存 id，不复制数据**），
  待办仍在待办模块里管理与完成；关联的待办被删除后该条显示「已失效」并可解除关联。
- **投入记录**：每次投入记一笔（分钟 + 备注），累计出「这个任务一共花了多少时间」，
  并给出近 12 周每周投入的柱状图。
- **停滞提醒**：最近活动 = max(任务更新时间, 最近一次投入)；超过 **14 天**没有活动、
  且任务还在推进（进行中 / 暂停）时，列表与详情页会标出「停滞 N 天」，
  总览可用「停滞」筛选把它们单独挑出来。已完成 / 已放弃 / 回收站里的任务不提醒。
- **总览页**：钉住的排在「当前重心」分组最前；其余按状态分组（进行中 / 暂停 / 已结束）。
  每张卡片直接给出：进度、目标日期倒数（或超期天数）、最近活动 / 停滞天数、行动项数与投入合计。
- **回收站**：任务可移入回收站（恢复 / 彻底删除）；彻底删除会连同里程碑与投入记录一起清掉，
  但**不会删除关联的待办**。

### 9.1 子项目（层级）与加权进度（2026-10-11 新增）

- **子项目 = 任务本身**：一个任务可以挂任意多个子项目，子项目还能再挂子项目（多层）。
  子项目拥有任务的**全部能力**（里程碑、投入记录、行动项、自己的子项目）。
  数据上是 `parentId`（空 = 顶层）+ `order`（同级排序），结构变化后把同级重排为 `0..n-1`。
- **子项目只在任务详情页展示**（缩进 + 展开/折叠 + 每层字号递减），
  总览页只列**顶层任务**并在卡片上显示「子项目 x/y 了结」——
  否则总览会被层级淹掉。
- **「隐藏已了结」**：已完成 / 已放弃的子项目默认隐藏（详情页可一键显示），
  偏好记在 `settings/ui.json` 的 `hideResolvedSubtasks`。
- **调整层级**（详情页每行的「⋮」）：
  - **降一级**：挂到「上一个同级任务」下面；
  - **升一级**：与父任务平级（成为它的下一个同级）；
  - **上移 / 下移**：同级内调整顺序；
  - **移动到…**：弹出整棵任务树选新父级（可选「顶层」），
    会**拒绝移到自己或自己的子孙下面**（防止成环）。
- **父任务进度 = 子项目加权（递归）**，不是简单平均：
  - 三个因子：**工作量**（子树最底层节点数）、**已投入时间**（子树累计分钟）、
    **里程碑数**（子树总数）；
  - 三个因子先在**同一父节点的兄弟之间归一化到 0~1**（量纲不同，不归一化会被"分钟"碾压），
    再按比例合成；默认 **0.5 : 0.3 : 0.2**（工作量最稳定、投入依赖记录、里程碑容易被灌水）；
  - 比例可在**任务总览页右上角「进度权重」**里调整，存 `settings/ui.json` 的 `questWeights`；
  - 三个因子整组都失效时（例如把比例全给了"投入"但谁都没记投入）**整组等权回退**；
  - **没有子项目**时才回退到「有里程碑按里程碑、否则手动百分比」。
- **完成约束**：子项目必须**全部已了结**（已完成 **或** 已放弃）才允许把父任务设为已完成，
  否则提示还剩哪几条；**不自动完成**父任务。
  已放弃算已了结是刻意的 —— 否则放弃过的子项目会让父任务永远完不成。
- **删除 / 归档约束**：有子项目时**禁止**删除或归档，提示先处理子项目
  （移出到顶层或删除），避免"一次删除把整棵没做完的子树悄悄带走"。

## 10. 更新与卸载（2026-10-07 新增）

### 9.1 应用内一键更新（Windows / Android）
- **检查**：设置页「检查更新」手动触发；启动时也会**静默检查一次**（每天最多一次，
  网络失败不打扰用户）。数据源为 GitHub Releases 的 `releases/latest`。
- **提示**：显示新版本号、发布说明、安装包名与体积；可「跳过此版本」（记进偏好，不再提示）。
- **一键更新**：应用内下载 →（可选）备份数据 → 覆盖安装：
  - Windows：以 `/SILENT /SUPPRESSMSGBOXES /NORESTART /CLOSEAPPLICATIONS` 静默运行安装包，
    装完自动打开新版本；
  - Android：下载 APK → 申请「安装未知应用」权限 → 调起系统安装界面，确认即覆盖安装。
- **数据不变**：更新只替换程序文件，`文档\AllOneData` 完全不受影响。
- **兜底**：从 1.2.1 及更早版本升级时默认**先复制一份数据目录**再安装
  （那些版本的卸载程序会删数据，见 9.2）。

### 9.2 卸载与数据清理
- 卸载时**弹窗询问**「是否同时删除全部个人数据」，**默认按钮为「否」（保留数据）**。
- 选择「是」→ 连同文件夹删除 `文档\AllOneData`（日记 / 待办 / 习惯 / 课程 / 记账 /
  日历 / 附件 / 地图瓦片 / 设置），即**全部使用痕迹**。
- 安装新版时会自动卸载旧版，但安装脚本**不再无条件删除数据目录**
  （1.2.1 及更早的旧脚本有此隐患，用它升级会静默删数据，已修复并成为默认行为）。

### 9.3 发布签名（前提条件）
- Android 只允许**签名一致**的 APK 覆盖安装，因此发布必须使用固定的
  `android/allone-release.jks`（随仓库保存，个人自用项目）；用 debug 签名会导致
  新版本装不上、只能卸载重装（数据全丢）。详见 [构建指南](BUILD.md)。

## 10. 编辑模式

- 日记书写时符合手机与电脑的键盘习惯，提供**两套编辑模式**：
  1. **手机模式**：触屏友好、大按钮、语音输入优先。
  2. **电脑模式**：全键盘、快捷键、Markdown 直接编辑。

## 11. 数据与同步

- 数据全部本地存储，采用**通用格式**（详见 `DATA_FORMAT.md`）。
- 提供**备份/恢复**功能：
  - U 盘手动备份（复制数据目录）——默认推荐方式。
  - 可选：加密云同步（设计预留接口，默认关闭）。
- 大文件（视频等）支持外链引用，减小备份体积。

## 12. 界面风格

- 简洁**白色**主题。
- 字体与组件使用成熟方案（Material 3 / 系统默认）。
- 强调可读性与稳定性，不追求花哨。

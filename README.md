# AllOne

**AllOne** 是一个个人全功能生活管理软件，将六大核心功能整合到一个跨平台应用中：

> 📔 日记 · ✅ 待办事项 · 🔁 习惯 · 🏫 课程表 · 💰 记账 · 📅 日历

数据**完全本地保存**、**格式通用**（JSON / 纯文本），支持 **U 盘手动备份**，信息安全第一、运行稳定、模块化风险隔离。

## ✨ 功能一览

| 模块 | 核心能力 |
|------|----------|
| **日记** | 纯文本编辑（类似 txt，手机·电脑键盘友好）、日记模板、标签戳 / 时间戳（**一键快捷节点：一个月/半年/一年**，到点置顶）/ 地址戳（**内嵌地图可视化选点**，详情页也显示地图）、照片 / 录音 / 视频 / 文件附件（**附件行点一下即打开**：照片全屏可缩放、录音内置播放器、**内嵌视频播放**）、大视频外链引用、**导入外部日记（txt / PDF，按日期自动分篇，只新增不覆盖）** |
| **待办** | 纯文本编辑（类似 txt）、**待办模板**（内容+截止+地点+标签一键套用）、截止时间与地点（颜色 + 醒目高亮）、附件按钮、标签、**树形待办**（普通待办可无限嵌套子任务，每个子任务都具备完整功能：标题/正文/截止/地点/标签/附件）、**回收站**（已完成项自动移入，支持恢复/彻底删除）、任务链默认收起 |
| **习惯** | 三维度打卡（**频率**：每天 / 每周几天 / 每 N 天 / 每周 N 次；**当天目标**：一次即完成 / 定量 / 时长；**坚持周期**：不限 / 坚持 N 天 / 累计 N 次 / 每轮 N 天循环）、**完成 / 失败**两种打卡（失败不计入完成与连续）、分类、目标进度、连续打卡统计、**纯文本描述**、**附件与标签**、习惯可随时编辑、**完成后自动移入回收站**（可恢复） |
| **课程表** | 学期制（半年一换）、每周视图（**网格 / 按天两种排布可切换并记住选择**，默认按窗口宽度自动选：宽屏 7 列铺满、手机按天竖排，不用左右翻）、课程集中统计（含课程说明）、上课周次（**已加入底部主导航**）、**从照片识别创建课程**（拍照/选图自动提取课程名 / 教室 / 时间 / 星期 / 周次，本地离线识别，仅安卓 / iOS） |
| **记账** | 总账本、自由创建多账户、收支流水、**今日 / 本月 / 本年三视图**、**每个账户与总账本分别做月 / 年统计**、**本月预算与日均支出 / 剩余每天可花**、**手机端快捷记账**（粘贴账单自动解析金额 / 日期 / 分类，自动判断是否已记录并填充） |
| **日历** | 当天（聚合**日记** / 待办 / 习惯 / 课程，按时间排序，顶部提示今天的特殊日子）、当月（完成情况可视化 + 特殊日子（**颜色任意自定义，可编辑**）+ **内置法定节假日 / 传统节日**）、当年（12 月概览）、**特殊日子 · 倒数日总览页**（按时间排列、倒数天数、**每年重复**的生日 / 纪念日） |
| **地图与定位** | **系统定位**（手机 GPS，离线可用，一键定位到当前位置）、**多底图源可切换**（Esri 街道/影像 · 高德 · 腾讯 · OSM，设置里切换）、**离线瓦片**（`AllOneData/map_tiles/{z}/{x}/{y}.png` 优先读取） |
| **备份** | 一键导出 zip（U 盘手动备份）、从 zip 恢复、**一键导出通用文本（Markdown / txt，可用记事本打开）**、**可排除回收站内容与旧附件以减小体积**、**回收站按时间清理** |

## 🛠 技术栈

- **Flutter 3.47**（一套代码覆盖 Android / Windows / iOS / iPadOS）
- **Riverpod**：模块化状态管理
- **flutter_map**：离线优先地图（地址戳选点）
- **Google ML Kit**：本地离线文字识别（课程表照片 OCR，Android / iOS）
- **syncfusion_flutter_pdf / fast_gbk**：外部日记导入（PDF 文本提取 / GBK txt 解码）
- **archive / share_plus**：备份打包与分享
- 文件系统 + JSON 存储（通用格式，便于备份与迁移）

## 🚀 运行

```bash
flutter pub get
flutter run          # 在已连接的设备 / 模拟器运行
```

平台要求：

- **Android**：需安装 Android SDK（Android Studio 或命令行工具）
- **Windows**：需安装 Visual Studio（"使用 C++ 的桌面开发"工作负载）
- **iOS / iPadOS**：代码跨平台就绪，需在 macOS + Xcode 上编译

> 开发期间可在 Chrome 中快速预览：`flutter run -d chrome`

## 💾 数据与备份

- 所有数据保存在系统「文档」目录的 `AllOneData/` 下（JSON + 附件，格式通用），**与程序文件（.exe）完全分离**，传播程序不会带走数据。
- 底部导航栏提供**所有主功能快捷入口**（可在「工具 → 底部导航显示设置」中选择哪些显示，避免拥挤），让界面更简洁。
- 工具页顶部提供**「功能导航」**：一键切换到任意主功能（日记 / 待办 / 习惯 / 课程 / 记账 / 日历）。
- 工具页集中收纳：**数据备份与迁移**（导出 zip、导入、导出通用文本）、**数据管理**（数据目录 / 大小 / 与程序分离说明）、**模板管理**（日记 / 待办模板）、**关于 AllOne**。
- 设置页另有：导出 zip 备份、**导出通用文本**（Markdown / txt，可用记事本打开）、从备份恢复、「打开数据目录」。
- 云同步默认关闭，确保隐私安全。

## 🧮 快捷记账（手机端）

- 复制一条账单消息（支付宝 / 微信 / 银行短信）后，在记账页 FAB →「快捷记账」，
  自动读取剪贴板并解析出**金额 / 日期 / 分类 / 备注**；
  同时**自动判断该笔是否已记录**（同账户·同日期·同金额·同分类），重复时给出醒目提示。

## 📅 内置节假日

- 日历「当月」视图自动标注**法定节假日与传统节日**（元旦 / 春节 / 清明 / 端午 / 中秋 / 国庆等，含农历算法），
  另可在日历界面手动添加个人特殊日子。

## 📥 导入外部日记（txt / PDF）

把之前在其他软件（记事本、印象笔记、OneNote、其他日记 App）写的日记搬进 AllOne：

- **入口**：日记页右上角「导入」按钮，或「工具 → 数据备份与迁移 → 导入外部日记」。
- **来源**：可多选 `.txt`（自动识别 UTF-8 / GBK 编码，中文不乱码）与文本型 `.pdf`。
- **自动分篇**：识别 `2024年5月1日 晴`、`2024-05-01`、`20240501` 这类日期行把长文件拆成多篇；
  也可选择「整篇作为一篇」「按空行分段」。识别到的日期即日记日期，日历与时间轴顺序与原来一致。
- **导入前预览**：逐篇看标题 / 日期 / 字数 / 来源，可单独勾选、可预览全文。
- **只新增不覆盖**：每篇都分配全新 ID 新增写入，**不会修改、覆盖或删除任何已有日记**；
  按「标题 + 日期 + 正文」自动识别疑似重复项并默认跳过（可关闭）。
- **统一标签**：可为本次导入的所有日记统一打标签（默认「导入」），便于日后回溯。
- **限制**：扫描件（图片型 PDF）没有文字层，请先在原软件导出 txt 或文字版 PDF。

## 🗺 地图与定位

**定位**：地址戳页面右上角的 ◎ 按钮调用系统定位（手机 GPS），**不需要网络**。
定位权限被拒或设备不支持时会明确提示。取自 `lib/core/utils/location_service.dart`。

**在线底图**：默认使用 **Esri 世界街道图**。
> 为什么不用 OSM 官方：`tile.openstreetmap.org` 等境外源在国内常被 DNS 污染 / 直连超时，
> 会导致地图**整块空白**（看起来像 bug，实际是网络）。实测本机在**未开 VPN** 时
> OSM / Carto / OpenTopoMap 全部超时，而 Esri、高德、腾讯正常。

可在「**设置 → 地图底图**」切换 5 个源：

| 源 | 说明 |
|----|------|
| Esri 街道图（默认） | 官方服务，国内可直连 |
| Esri 卫星影像 | 同上，影像底图 |
| 高德地图 | 国内快；**GCJ-02 坐标**，与 GPS 有几十米偏移 |
| 腾讯地图 | 同上，GCJ-02 |
| OpenStreetMap | 传统源；国内多数网络需配合代理/VPN |

**离线地图**：需要**完全离线**时，把标准 XYZ 瓦片放入
`AllOneData/map_tiles/{z}/{x}/{y}.png`（可用 Mobile Atlas Creator / OSMAnd 等导出）。
本地有瓦片时优先读本地，没有才走在线源。
> 项目**不内置**任何地图数据；离线能力取决于你自己提供的瓦片。

| 平台 | 产物 | 说明 |
|------|------|------|
| **Windows** | `AllOne_Setup_vX.Y.Z.exe` | Inno Setup 安装包：安装向导、开始菜单/桌面快捷方式、卸载程序；安装时自动创建数据目录；**卸载时询问是否删除数据（默认保留）** |

## 🔄 应用内更新（电脑 / 手机都是一键）

- **入口**：设置页 →「检查更新」；启动时也会**静默检查一次**（每天最多一次，失败不打扰）。
- 检查的是 [GitHub Releases](https://github.com/yb123654789/AllOne/releases) 上最新一次发布，
  发现新版本会显示版本号、更新说明与安装包大小。
- 点「下载并更新」后：应用内**下载 →（可选）备份数据 → 覆盖安装**，
  **只替换程序文件，`文档\AllOneData` 里的日记 / 待办 / 附件完全不动**。
  - Windows：静默运行安装包（`/SILENT`）覆盖升级，装完自动打开新版本；
  - Android：调起系统安装界面，确认即覆盖安装（需「安装未知应用」权限）。
- 可以点「跳过此版本」不再提示该版本。
- 从 **1.2.1 及更早版本**升级时，安装包会默认**先复制一份数据目录**再升级
  （那些旧版本的卸载程序会删数据，详见下方「卸载与数据」）。

### ⚠️ Android 必须用固定签名

Android 只允许**签名一致**的 APK 覆盖安装，所以本项目把发布密钥
`android/allone-release.jks` 与 `android/key.properties` **随仓库保存**（个人自用项目）。
丢失密钥 = 以后无法覆盖升级（只能卸载重装，而卸载会删数据）。
详见 [构建指南 → Android 发布签名](docs/BUILD.md)。

## 🗑 卸载与数据

- **数据与程序分离**：程序装在 `%LOCALAPPDATA%\Programs\AllOne`，数据在 `文档\AllOneData`；
  卸载程序**默认保留**数据（弹窗默认「否」），想彻底清理就选「是」——
  会连同文件夹一起删除 `AllOneData`（日记 / 待办 / 附件 / 地图瓦片 / 设置，即全部使用痕迹）。
- **升级不会碰数据**：安装新版时虽然会自动卸载旧版，
  但安装脚本已不再无条件删除数据目录（旧版本 1.2.1 及更早有此隐患，已修）。


> 产物文件名带版本号，版本号取自 `pubspec.yaml`；发布前需同步
> `installer/AllOne_setup.iss` 的 `MyAppVersion`。

## 🔨 构建

- **Windows**：`flutter build windows --release` → 产物在 `build/windows/x64/runner/Release/`
  （**必须在纯英文路径下构建**：Flutter 的 Windows 工具链在含中文的路径下会报
  `Unable to read file ... app.dill`，因为路径按 GBK 解释而实际是 UTF-8）
- **Windows 安装包**（需 Inno Setup 6，ISCC）：上面构建后运行 `ISCC.exe installer/AllOne_setup.iss`
- **Android APK**：`flutter build apk --release`
  - 环境要求：JDK 17 + Android SDK（compileSdk 36 / build-tools / platform-tools）
  - 已知问题：插件 `file_picker`（8.x）硬编码 `compileSdk 34`，与本项目所需的 36 冲突时，需将 pub 缓存中该插件 `android/build.gradle` 的 `compileSdk 34` 改为 `36`（或升级到 12.x 并适配新 API）
- **linux/macOS**：未适配，不在 CI 范围

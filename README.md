# AllOne

**AllOne** 是一个个人全功能生活管理软件，将六大核心功能整合到一个跨平台应用中：

> 📔 日记 · ✅ 待办事项 · 🔁 习惯 · 🏫 课程表 · 💰 记账 · 📅 日历

数据**完全本地保存**、**格式通用**（JSON / 纯文本），支持 **U 盘手动备份**，信息安全第一、运行稳定、模块化风险隔离。

## ✨ 功能一览

| 模块 | 核心能力 |
|------|----------|
| **日记** | 纯文本编辑（类似 txt，手机·电脑键盘友好）、日记模板、标签戳 / 时间戳（**一键快捷节点：一个月/半年/一年**，到点置顶）/ 地址戳（**内嵌地图可视化选点**，详情页也显示地图）、照片 / 录音 / 视频 / 文件附件、**内嵌视频播放**、大视频外链引用 |
| **待办** | 纯文本编辑（类似 txt）、**待办模板**（内容+截止+地点+标签一键套用）、截止时间与地点（颜色 + 醒目高亮）、附件按钮、标签、**树形待办**（普通待办可无限嵌套子任务，每个子任务都具备完整功能：标题/正文/截止/地点/标签/附件）、**回收站**（已完成项自动移入，支持恢复/彻底删除）、任务链默认收起 |
| **习惯** | 三维度打卡（**频率**：每天 / 每周几天 / 每 N 天 / 每周 N 次；**当天目标**：一次即完成 / 定量 / 时长；**坚持周期**：不限 / 坚持 N 天 / 累计 N 次 / 每轮 N 天循环）、**完成 / 失败**两种打卡（失败不计入完成与连续）、分类、目标进度、连续打卡统计、**纯文本描述**、**附件与标签**、习惯可随时编辑、**完成后自动移入回收站**（可恢复） |
| **课程表** | 学期制（半年一换）、每周视图、课程集中统计（含课程说明）、上课周次（**已加入底部主导航**）、**从照片识别创建课程**（拍照/选图自动提取课程名 / 教室 / 时间 / 星期 / 周次，本地离线识别，仅安卓 / iOS） |
| **记账** | 总账本、自由创建多账户、收支流水、**今日 / 本月 / 本年三视图**、**每个账户与总账本分别做月 / 年统计**、**本月预算与日均支出 / 剩余每天可花**、**手机端快捷记账**（粘贴账单自动解析金额 / 日期 / 分类，自动判断是否已记录并填充） |
| **日历** | 当天（聚合**日记** / 待办 / 习惯 / 课程，按时间排序）、当月（完成情况可视化 + 特殊日子 + **内置法定节假日 / 传统节日**）、当年（12 月概览） |
| **备份** | 一键导出 zip（U 盘手动备份）、从 zip 恢复、**一键导出通用文本（Markdown / txt，可用记事本打开）** |

## 🛠 技术栈

- **Flutter 3.47**（一套代码覆盖 Android / Windows / iOS / iPadOS）
- **Riverpod**：模块化状态管理
- **flutter_map**：离线优先地图（地址戳选点）
- **Google ML Kit**：本地离线文字识别（课程表照片 OCR，Android / iOS）
- **archive / share_plus**：备份打包与分享
- 文件系统 + JSON 存储（通用格式，便于备份与迁移）

## 🚀 运行

```bash
flutter pub get
flutter run          # 在已连接的设备 / 模拟器运行
```

平台要求：

- **Android**：需安装 Android SDK（Android Studio 或命令行工具）
- **Windows**：需安装 Visual Studio（"使用 C++ 的桌面开发"工作负载）
- **iOS / iPadOS**：代码跨平台就绪，需在 macOS + Xcode 上编译

> 开发期间可在 Chrome 中快速预览：`flutter run -d chrome`

## 💾 数据与备份

- 所有数据保存在系统「文档」目录的 `AllOneData/` 下（JSON + 附件，格式通用），**与程序文件（.exe）完全分离**，传播程序不会带走数据。
- 底部导航栏提供**所有主功能快捷入口**（可在「工具 → 底部导航显示设置」中选择哪些显示，避免拥挤），让界面更简洁。
- 工具页顶部提供**「功能导航」**：一键切换到任意主功能（日记 / 待办 / 习惯 / 课程 / 记账 / 日历）。
- 工具页集中收纳：**数据备份与迁移**（导出 zip、导入、导出通用文本）、**数据管理**（数据目录 / 大小 / 与程序分离说明）、**模板管理**（日记 / 待办模板）、**关于 AllOne**。
- 设置页另有：导出 zip 备份、**导出通用文本**（Markdown / txt，可用记事本打开）、从备份恢复、「打开数据目录」。
- 云同步默认关闭，确保隐私安全。

## 🧮 快捷记账（手机端）

- 复制一条账单消息（支付宝 / 微信 / 银行短信）后，在记账页 FAB →「快捷记账」，
  自动读取剪贴板并解析出**金额 / 日期 / 分类 / 备注**；
  同时**自动判断该笔是否已记录**（同账户·同日期·同金额·同分类），重复时给出醒目提示。

## 📅 内置节假日

- 日历「当月」视图自动标注**法定节假日与传统节日**（元旦 / 春节 / 清明 / 端午 / 中秋 / 国庆等，含农历算法），
  另可在日历界面手动添加个人特殊日子。

## 🗺 离线地图

- 地址戳默认使用在线瓦片；需要**完全离线**时，将标准 XYZ 瓦片放入
  `AllOneData/map_tiles/{z}/{x}/{y}.png`（可用 Mobile Atlas Creator / OSMAnd 等导出）。

## 🔨 构建

- **Windows 安装包**（需 Inno Setup 6，ISCC）：`flutter build windows --release` 后运行 `ISCC.exe installer/AllOne_setup.iss`
- **Android APK**：`flutter build apk --release`
  - 环境要求：JDK 17 + Android SDK（compileSdk 36 / build-tools / platform-tools）
  - 已知问题：插件 `file_picker`（8.x）硬编码 `compileSdk 34`，与本项目所需的 36 冲突时，需将 pub 缓存中该插件 `android/build.gradle` 的 `compileSdk 34` 改为 `36`（或升级到 12.x 并适配新 API）
